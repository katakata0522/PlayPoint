学マスはWEB SHOPとGoogle Playどっち？ジュエル数・DMMとの違いを比較

結論：スマホで使うジュエルなら、WEB SHOPの増量も比べたい

学マスでジュエルを買うなら、アプリ内の購入画面と公式WEB SHOPを見比べる価値があります。WEB SHOPには通常商品の増量に加え、回数限定の商品もあります。一方、Google Playで決済する購入には、条件に応じてPlay Pointsが付きます。

先に確認したいのは遊ぶ端末です。WEB SHOPで購入したジュエルはスマートフォン版用で、DMM版では使えません。価格だけを見て買うと、この違いで戸惑いやすくなります。

公式WEB SHOPで確認できた価格

2026年9月26日に、ログイン前の公式WEB SHOPで確認した表示です。回数限定商品の残り回数は自分の購入履歴で変わるため、ログイン後にも確認してください。

WEB SHOPの表示例（税込・2026年9月26日確認）
商品価格表示ジュエル数条件
通常ジュエル480円380個20個増量の表示
通常ジュエル4,800円4,250個250個増量の表示
通常ジュエル9,800円8,700個500個増量の表示
WEB SHOPリリース記念480円1,000個1回きり
WEB SHOPリリース記念4,800円6,000個2回きり
WEB SHOPリリース記念9,800円12,300個2回きり

商品詳細では、通常9,800円の8,700個と記念480円の1,000個は、いずれも有償ジュエルと表示されていました。ほかの商品も、合計だけでなく有償・無償の内訳を開いて確認すると、使いたいガシャに合うかを判断しやすくなります。

この表はWEB SHOP側の実際の表示です。Androidアプリ内の現在価格を取得した表ではないため、アプリ側は自分の購入画面の金額・個数と並べて比較してください。期間限定パスも同じ売り場にあるので、ジュエル商品と取り違えないようにしましょう。

Play Pointsを足して比べるときの考え方

まず「支払額」と「その金額でもらえるジュエル数」を比べます。WEB SHOPの増量分はゲーム内で使えるジュエル、Play Pointsは後からクーポンやPlayクレジットなどへ交換するポイントで、同じものではありません。

たとえば、Android側に9,800円で8,200個と表示されているなら、WEB通常商品の8,700個との差は500個です。その500個と、Google Play購入で付く予定ポイントを、自分の使い道で比べます。アプリ側の個数が違えば、この差も変わります。

ポイントの目安は税抜価格から計算します。税込9,800円・消費税10％を前提にすると、100円につき1ptで約89pt、100円につき7ptが適用される購入なら約624ptです。7ptの条件が自分に表示され、対象購入に適用される場合の例なので、購入確認画面の獲得予定ポイントも見てください。

WEB SHOPの支払いにはGoogle Play Pointsは付きません。購入額を決めたら学マスのPlayポイント計算機でアプリ内購入の目安を確認できます。

iPhone・Android・DMMで、ジュエルはどう扱われる？

バンダイナムコの公式FAQによると、WEB SHOPで買ったジュエルはスマートフォン版のiOS・Google両方で共有されます。DMM版には反映されません。

これは「WEB SHOPで買ったジュエル」の説明です。購入先が異なるジュエル全般を、同じルールだと読み替えないようにしてください。DMM版で主に遊んでいる人は、使う端末と購入先を先にそろえて考えると安心です。

購入前は、連携先のプロデューサーを確認する

WEB SHOPの利用案内では、ゲームとバンダイナムコIDの連携が必要とされています。連携したゲームアカウントへ商品が付くので、ログイン後のアカウント情報が普段使っているプロデューサーのものか確認しましょう。

商品詳細には、WEB購入の直前にスマートフォン版で購入操作をしないこと、プリペイド型クレジットカードは使えないことも案内されています。誤ったプロデューサー情報で購入した後のキャンセルは受け付けないという注意もあるため、決済ボタンの前に一度見直すのがおすすめです。

買ったのに増えないときは、まずスマホ版を開く

DMM版を見ているなら、同じ連携先のiOS／Android版で確認します。公式の未反映FAQも、WEB購入分はスマホ版のみで使えることを案内しています。

スマホ版でも確認できない場合は、購入先と連携アカウント、注文の状態を確かめてから公式サポートへ相談しましょう。反映を急いで同じ商品を買い直す前に、どこで購入したかを整理することが大切です。
