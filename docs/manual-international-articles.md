# 多言語記事の正本管理

一部の英語・韓国語・繁体字記事は、地域別の事実確認と編集内容を保持するため、公開HTMLを手動管理の正本として扱います。

## 編集手順

1. 対象のHTMLを編集する。
2. `node scripts/build-html.js` を実行する。
3. `node .github/scripts/preflight.cjs` を実行する。
4. 生成差分と地域別回帰テストを確認する。

手動管理対象は `scripts/manual-intl-articles.cjs` の一覧を正本として管理します。この一覧に入った記事は国際記事台帳へ `manual` 所有権が自動反映され、自動生成側の対象から除外されます。対象を追加・削除するときは一覧と回帰テストを同じ変更で更新し、別の所有権一覧を増やさないでください。

公開HTMLだけを生成対象として扱うのか、手動管理の正本として扱うのかを曖昧にしないことが再発防止の基本ルールです。
