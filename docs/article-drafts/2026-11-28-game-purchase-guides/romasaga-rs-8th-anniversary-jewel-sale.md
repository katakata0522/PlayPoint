# ロマサガRS8周年ジュエルセール｜無料Webパック・有償ジュエルと販売期限

ロマサガRSの8周年は、ジュエルの入手機会が増える時期でもあります。無料の配布がある一方、有償ジュエルが必要な商品もあるので、いま持っている分で何が買えるかを整理しておきたいですね。

## 無料Webパックと周年セールは2027年1月1日4時まで予定

8周年記念パックは無償・有償ジュエルのどちらでも購入でき、上限5回です。Webジュエルショップでは無料パックとジュエルセールも案内されています。買い物の前に、無料分と有償限定商品を分けて考えてみましょう。

## 先に受け取れる無料分を把握する

超感謝ログインボーナスの45,000ジュエルは期間中の最大30日間のログインで受け取るものです（2027年2月1日4:00まで）。これとは別に、5日間で3,000ジュエルの第1弾ログインボーナスと、1日ログインで200ジュエルの自動編成記念ボーナスもあります。記念パネルミッションの全達成報酬は5,000ジュエルですが、ログインだけでもらえる分ではありません。

ログイン3企画の最大合計は48,200ジュエル、パネルミッションの全達成分を含めると53,200ジュエルです。一度ログインしただけで全額もらえるわけではありません。無料Webパックの内容はこのジュエル合計には加えていません。ログイン回数や各ミッションを満たした場合の合計で、今後受け取れる残りの額はプレイ状況で異なります。

これらとは別に、スクウェア・エニックスの11月27日メンテナンス告知には協力のお礼200ジュエルと不具合修正のお詫び100ジュエルの配布案内があります。12月28日4:00までにログインした人が対象で、プレゼントボックスから受け取る案内です。周年企画の53,200ジュエルとは別枠として扱い、受取済みの分は重複して数えません。 [メンテナンス告知](https://support.jp.square-enix.com/news.php?drt=1795510800&id=17621&la=0&n=2&tag=c8853e26a637e7c3d347ac051a3f1c228848b0e6)

無料Webパックも含め、受取条件と終了日を先に見ておけば、有償ジュエルを買う予定が変わるかもしれません。

## 無償ジュエルで買えるもの、有償限定のもの

ゲーム内8周年記念パックはどちらのジュエルでも購入可能で、5回までと発表されています。パックには10回ガチャで対象のSSスタイル1体が確定するチケットが含まれ、対象ガチャは2027年1月8日4:00までです。一方、同時期のソウルピースパックには有償限定の商品があり、周年ステップガチャにも有償条件があります。無料分を受け取ったあとで、欲しいものの購入条件を見てみましょう。

## 記念パックは何回受け取る？　有償限定品と予算を分ける

運営の公式発表で確定しているのは、ゲーム内8周年記念パックが有償・無償どちらのジュエルにも対応し、5回まで購入可能という点です。Webの無料パックも別途告知されています。

ゲーム内お知らせを掲載したGamerchの資料では、ゲーム内記念パックの1回目は無料、2回目1,000、3回目2,000、4・5回目は各3,000ジュエルと報告されています。一次の個別商品画面はまだ取得できていないため、下表は照合待ちの参考値です。

| ---: | ---: | ---: |
| 1回目 | 0 | 0 |
| 2回目 | 1,000 | 1,000 |
| 3回目 | 2,000 | 3,000 |

ゲーム内とWeb無料パックの取得回数が共有されているかは未確認です。両方で必ず受け取れると考えず、それぞれの受取表示を確認しましょう。 [ゲーム内告知の掲載資料（二次情報）](https://gamerch.com/saga-reuniverse/1036836)

周年の有償限定ソウルピースパックは10,800枚・3,600枚が各1回と公式発表にあります。こよみ編・エロール編の有償ステップガチャではステップ2・4が無料、ステップ6はSS1体、ステップ7はピックアップSS1体確定です。2周目はステップ1・3が有償1,000ジュエル、2周目のステップ7は未所持のピックアップSS1体確定と案内されています。無料の配布ジュエルで有償ステップをすべて実行できるという意味ではありません。全ステップの必要有償ジュエルは今回確定できていないため、合計金額は断定しません。

## Webジュエルショップで買うなら、アカウント連携から

公式の利用案内では、スクウェア・エニックス アカウントを用意し、ゲーム内のホーム→メニュー→メール登録で連携する必要があります。購入後はタイトル画面からログインするか、ジュエル購入画面の「更新」を押すと反映できます。

有償ジュエルは残高に直接加わりますが、無償ジュエルとおまけはプレゼントボックスに届きます。プレゼントボックスが200件以上の場合、購入したジュエルやおまけが一覧に表示されないことがあります。既存のプレゼントを受け取ってから再確認しましょう。

個別の円価格・有償ジュエル数は、まだ公式商品画面から直接取得できていません。同じ商品を両方の購入画面で見比べ、支払額をジュエル数で割って単価を求めましょう。有償限定商品を買いたい場合は、有償分だけの単価で比べるのがポイントです。

## Webセールは大きい金額ほど得？　参考価格で単価を比較

同じGamerchの告知掲載資料には、Webジュエルショップのセールが990円で有償1,500個とソウルピース100個、9,900円で有償15,000個とソウルピース1,000個、各6回までと記載されています。

| 商品（一次商品画面未確認の参考値） | 円価格 | 有償ジュエル単価 |
| --- | ---: | ---: |
| 1,500ジュエル | 990円 | 0.66円 |
| 15,000ジュエル | 9,900円 | 0.66円 |

二次資料に記載された商品条件なら、どちらも同じ単価で、おまけの比率も同じです。欲しい有償分が少ない場合、金額が大きい方を選ばなくても単価は変わりません。日本向けの公式ストア商品画面を直接照合できるまでは、現在価格・アプリ内との優劣は確定しません。

## Google Playの還元を含めるなら

予定している購入に使える割引や獲得予定のPlay Pointsを実質負担に含められます。Webショップ側のおまけも実際に使うものだけを評価しましょう。まず無料分を受け取ってから、それでも足りない有償分を考えるのが気持ちよく周年を楽しむ方法です。
