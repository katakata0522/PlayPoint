# ロマサガRS8周年ジュエルセール｜無料Webパック・有償ジュエルと販売期限

ロマサガRSの8周年は、ジュエルの入手機会が増える時期でもあります。無料の配布がある一方、有償ジュエルが必要な商品もあるので、いま持っている分で何が買えるかを整理しておきたいですね。

## 無料Webパックと周年セールは2027年1月1日4時まで予定

8周年記念パックは無償・有償ジュエルのどちらでも購入でき、上限5回です。Webジュエルショップでは無料パックとジュエルセールも案内されています。買い物の前に、無料分と有償限定商品を分けて考えてみましょう。

## 先に受け取れる無料分を把握する

8周年の超感謝ログインボーナスは最大30日間のログインで合計45,000ジュエルが案内されています。開催は2027年2月1日4:00まで。さらにWebジュエルショップでは無料の8周年記念パックが2027年1月1日4:00まで予定されています。

## 販売と受取の期限を混同しない

| 内容 | 公式の終了予定（日本時間） |
| --- | --- |
| ゲーム内8周年記念パック | 2027/1/1 4:00 |
| Webの無料8周年記念パック | 2027/1/1 4:00 |
| Web・ゲーム内ジュエルセール | 2027/1/1 4:00 |
| 記念パックのチケット対象ガチャ | 2027/1/8 4:00 |
| 超感謝ログインボーナス | 2027/2/1 4:00 |

商品の購入期限とチケットの利用期限は別に確認します。 [8周年の公式発表](https://games.aktsk.jp/news/62839/)

## 無償ジュエルで買えるもの、有償限定のもの

8周年記念パックはどちらのジュエルでも購入可能で、5回までと発表されています。一方、同時期のソウルピースパックには有償限定の商品があり、周年ステップガチャにも有償条件があります。無料分を受け取ったあとで、欲しいものの購入条件を見てみましょう。

## Webジュエルショップで買うなら、アカウント連携から

公式の利用案内では、Webジュエルショップにはスクウェア・エニックス アカウントが必要です。無料パックも買い物も、ゲームとの連携が済んでいるかが出発点になります。個別の円価格・有償ジュエル数はまだ直接取得できていません。同じ商品を両方の購入画面で見比べ、支払額をジュエル数で割って単価を求めましょう。有償限定商品を買いたい場合は、有償分だけの単価で比べるのがポイントです。

## Google Playの還元を含めるなら

予定している購入に使える割引や獲得予定のPlay Pointsを実質負担に含められます。Webショップ側のおまけも実際に使うものだけを評価しましょう。まず無料分を受け取ってから、それでも足りない有償分を考えるのが気持ちよく周年を楽しむ方法です。
