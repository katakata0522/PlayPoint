# にゃんこ大戦争14周年｜大感謝パック・超限定セール第2期はいつまで？

14周年のお祝いが続くにゃんこ大戦争。11月28日は大感謝パックと超限定セールの切り替わりの日です。いつまで何を受け取れるのか、買い物に関係する情報を整理しました。

## 第2期の販売予定は11月28日11時から12月12日10:59まで

14周年の限定商品は第2期へ切り替わります。先ににゃんこスロットⅡなどの無料分を受け取ってから、必要なネコカンやチケットを考えるのがおすすめです。第2期の商品別価格・内容はアプリ内の公式画面で確認してください。

## 買い物と無料受取の期限は別

| 内容 | 公式発表の期間（日本時間） |
| --- | --- |
| 大感謝パック・超限定セール 第2期 | 11/28 11:00〜12/12 10:59 |
| にゃんこスロットⅡ 第2回 | 11/26 11:00〜12/9 23:59 |
| レジェンドチケット販売 | 11/27 11:00〜12/25 10:59 |
| 14周年イベント全体 | 11/12 11:00〜12/25 10:59 |

スロットを回すと、公式案内では最低1,014個のネコカンが当たります。さらに30日間の記念ログインスタンプでにゃんこチケットとレアチケットを各10枚受け取れる企画も、2027年3月16日10:59まで予定されています。まず無料分を見てから、必要な購入額を考えたいですね。 [公式第2弾](https://battlecats.club/news/game/20261126_14th-event/)

## 買う前に、ネコカン以外の無料分も受け取れる

周年の無料報酬にはスロットだけでなく、達成条件のある特典も用意されています。

| 特典 | 受取条件 |
| --- | --- |
| ネコカン1,014個以上 | 第2回にゃんこスロットⅡに参加 |
| プラチナチケット1枚 | 日本編第1章クリアの記念ミッション（12/25 23:59まで） |
| ネコカン1回20個・期間合計最大880個 | 毎日0時に再登場するバースデープレゼント！ステージをクリア |
| にゃんこチケット・レアチケット各10枚 | 記念ログインスタンプを30日分受取 |

880個は第1弾からすべての日に受け取れた場合の公式上限で、11月28日から始めた人が残り期間で全数を受け取れるという意味ではありません。プラチナチケットは既に第1章をクリア済みの人も公式案内では対象ですが、ミッション達成・受取状況はゲーム内で確認しましょう。ミッション期限はイベント全体の終了時刻と異なります。 [周年公式告知](https://battlecats.club/news/game/20261126_14th-event/)

## 第2期の商品内容を第1期の数字で判断しない

公式発表では商品の名称と販売日程が案内されていますが、第2期の個別価格・ネコカン数・購入上限は今回の公開資料では確認できていません。第1期と同じ価格や内容とは決めず、アプリ内の告知と購入画面を見比べてください。

## 参考：第1期のパック価格と、継続商品の報告

ゲームエイトの掲載情報では、第1期の大感謝パックは1,500円でネコカン777個・レアチケット7枚です。レジェンドチケットは1,000円でチケット1枚・ネコカン10個（購入1回）、レアガチャネコパックは2,000円でEXキャラ「レアガチャネコ」・ネコカン750個・XP100万とされています。後者2商品の掲載上の販売期限は12月25日10:59です。大感謝パックの掲載期間は11月28日10:59までで、第2期の値段・中身を示すものではありません。公式の購入画面を直接確認できていない二次情報なので、購入前の参考に留めます。 [第2弾の掲載情報（ゲームエイト）](https://game8.jp/battlecats/834240)

## 限定セール以外にも、ネコカンの消費を抑えられる企画がある

第2弾の公式告知にはレアガチャの初回値引きとEXキャラクター半額セールも掲載されています。ガチャの初回価格、適用済みかどうか、半額対象はアプリ内表示が基準です。具体的なネコカン数は取得できていません。レジェンドチケットは通常のネコカンと用途が異なるので、手持ちの無料チケットや初回割引で目的が足りるなら、追加購入を急ぐ必要はありません。

## パックを比べるときは、ネコカンとチケットを分けよう

パックの価格をネコカンの個数で割ると、ネコカンだけで見た単価が分かります。レアチケットや素材が入る場合は、その中身も別に並べてみましょう。第2期の実売価格と数量が分かるまでは、具体的な金額や割引率は出さず、通常商品との比較を保留します。

## Google Playと公式オンラインショップも確認

14周年中に買う場合でも、Google Playの対象購入とWebショップで受け取る独自特典は別。公式オンラインショップは11月25日にゲーム内商品の販売を始めました。にゃんこ大商店は税抜購入額の1%の独自ポイントが付きますが、ゲーム内商品はショップのクーポン対象外です。同じ周年商品を両方で販売しているとは限らないため、商品名・購入制限と、利用できるポイントをそろえて比べましょう。 [ショップ公式FAQ](https://www.nyanko-daishoten.jp/Page/guide_faq.aspx)

## 周年は、無料分から楽しむ

限定セールは買う予定がある人にとってうれしい機会ですが、無料の受取分だけで足りるなら、それも十分にお得な選び方です。まず自分のネコカンを見て、必要な分だけ考えてみてください。
