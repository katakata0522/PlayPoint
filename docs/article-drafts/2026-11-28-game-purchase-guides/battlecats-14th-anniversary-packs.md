# にゃんこ大戦争14周年の大感謝パックはいつまで？ネコカン・限定商品と無料特典

14周年のお祝いが続くにゃんこ大戦争。11月28日は大感謝パックと超限定セールの切り替わりの日です。いつまで何を受け取れるのか、買い物に関係する情報を整理しました。

## 第2期の販売予定は11月28日11時から12月12日10:59まで

14周年の限定商品は第2期へ切り替わります。先ににゃんこスロットⅡなどの無料分を受け取ってから、必要なネコカンやチケットを考えるのがおすすめです。第2期の商品別価格・内容はアプリ内の公式画面で確認してください。

## 買い物と無料受取の期限は別

| 内容 | 公式発表の期間（日本時間） |
| --- | --- |
| 大感謝パック・超限定セール 第2期 | 11/28 11:00〜12/12 10:59 |
| にゃんこスロットⅡ 第2回 | 11/26 11:00〜12/9 23:59 |
| レジェンドチケット販売 | 11/27 11:00〜12/25 10:59 |
| 14周年イベント全体 | 11/12 11:00〜12/25 10:59 |

スロットでは公式案内上1,014個以上のネコカンを受け取れる機会があります。受取分を計算に入れてから購入を考えると、欲しかったものに届くかが見えやすくなります。 [公式第2弾](https://battlecats.club/news/game/20261126_14th-event/)

## 第2期の商品内容を第1期の数字で判断しない

公式発表では商品の名称と販売日程が案内されていますが、第2期の個別価格・ネコカン数・購入上限は今回の公開資料では確認できていません。第1期と同じ価格や内容とは決めず、アプリ内の告知と購入画面を見比べてください。

## ネコカン単価だけで見るとどうなる？

仮に1,500円でネコカン777個のセットがあれば、ネコカンだけの単価は約1.93円です。通常商品が1万円で3,900個という仮定なら約2.56円。前者の単価が約24.7%低いことになります。これは価格の比較方法を示す例であり、第2期の販売内容ではありません。チケットや素材のおまけは利用する予定がある場合に別途考えます。

## Google Playと公式オンラインショップも確認

14周年中に買う場合でも、Google Playの対象購入とWebショップで受け取る独自特典は別。公式オンラインショップは11月25日にゲーム内商品の販売を始めました。同じ周年商品を両方で販売しているとは限らないため、商品名と購入制限をそろえて比べましょう。

## 周年は、無料分から楽しむ

限定セールは買う予定がある人にとってうれしい機会ですが、無料の受取分だけで足りるなら、それも十分にお得な選び方です。まず自分のネコカンを見て、必要な分だけ考えてみてください。
