## 計算と出典
- 割引による同一単価の分岐点は「Google Play価格 − Web価格 × Google Play数量 ÷ Web数量」。両方同額なら価格×(1−個数比)。増量率と必要割引率を混同しない。仮例・米ドルFAQ・日本の古いストア表示を混ぜて現行実売表にしない。
- 受取予定のポイントは税抜対象額×対象獲得率を丸める。利用価値は0円/ptを含め本人が決める。抽選・使わないおまけ・未取得のクーポンは確定還元に含めない。
