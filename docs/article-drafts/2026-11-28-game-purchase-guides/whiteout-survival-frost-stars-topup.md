# ホワイトアウト・サバイバルの課金比較｜寒霜の星とチャージポイントはどう違う？

パックを買うときに、寒霜の星やチャージポイント、Play Pointsという名前が並ぶと、どれがどの購入で貯まるのか少しややこしいですよね。別々の仕組みとして考えると、購入先の比較がしやすくなります。

## 寒霜の星の購入と、ゲーム内パックの購入特典を分ける

ホワサバの公式wikiでは、ゲーム内の有料パック購入で貯まるチャージポイントの目安が案内されています。公式ストアで寒霜の星を購入した段階と、それをゲーム内で使う段階の扱いは、地域別の公式規約を確認してから比較します。

## ゲーム内のチャージポイントの目安

公式wikiの案内には、有料パック購入時の目安として次の値が掲載されています。

| パック価格 | チャージポイントの目安 |
| ---: | ---: |
| 800円 | 2,500 |
| 1,600円 | 5,000 |
| 3,200円 | 10,000 |
| 8,000円 | 25,000 |
| 15,800円 | 50,000 |

これはPlay Pointsではありません。個別イベントのポイント付与条件や、受取報酬の利用価値とは分けて確認します。 [公式wiki](https://www.whiteoutsurvival.wiki/ja/vip-post/%E7%B7%8F%E5%90%88%E6%A1%88%E5%86%85/)

## 寒霜の星は、買う時と使う時を分ける

Web側で有料通貨を購入した時点で、すべてのゲーム内チャージイベントが進むとは限りません。日本向けの公式ストアの実際の商品一覧・チャージイベント規約を確認できていないため、固定の増量率やイベントへの加算をここでは断定しません。

## 購入先比較に必要な数字

比較には同じ円予算で購入できる寒霜の星の数量、ゲーム内で同一パックを購入するための数量、ゲーム独自の還元、Google Playのポイントを用います。仮にWeb側で5%多い同じ通貨を得られるなら、Google Play側の割引が約4.76%で同じ単価になります。これは計算例で、現在のホワサバの増量率ではありません。

## 公式の購入先であることを確かめる

ゲーム内の案内や開発元の公式サイトから購入先へ移動し、国・通貨・アカウントが合っていることを確認します。外部ストアの決済はGoogle Play購入とは別扱いです。価格や規約を確認できないまま、非公式チャージサービスを推奨することはしません。
