# ホワイトアウト・サバイバル（ホワサバ）課金｜寒霜の星と累計チャージの仕組み

パックを買うときに、寒霜の星やチャージポイント、Play Pointsという名前が並ぶと、どれがどの購入で貯まるのか少しややこしいですよね。別々の仕組みとして考えると、購入先の比較がしやすくなります。

## 寒霜の星を買う時ではなく、有料パックに使う時に累計チャージへ加算

公式wikiによると、寒霜の星を公式ショップで買っただけでは、累計チャージやダイヤ購入イベントの対象にはなりません。星でゲーム内の有料パックを買う段階で累計チャージに加算されます。Webで先に星を用意するときは、パックを購入するタイミングも大切なんですね。

## ゲーム内のチャージポイントの目安

公式wikiの総合案内には有料パック購入時のチャージポイントが、豊穣の宴FAQには同価格のパックを購入するための寒霜の星の必要数が掲載されています。2資料の対応する価格枠を並べた表です。

| パック価格 | 寒霜の星の必要数（公式wiki掲載例） | チャージポイントの目安 |
| ---: | ---: | ---: |
| 800円 | 499個 | 2,500 |
| 1,600円 | 999個 | 5,000 |
| 3,200円 | 1,999個 | 10,000 |
| 8,000円 | 4,999個 | 25,000 |
| 15,800円 | 9,999個 | 50,000 |

寒霜の星はパックを購入するのに必要な個数で、Webで買うときの獲得数ではありません。チャージポイントもPlay Pointsとは別の制度です。他のパックまで同じ必要数や獲得数であるとは断定せず、個別イベントの対象・現行の販売額はゲーム内の表示を優先してください。 [チャージポイントの公式案内](https://www.whiteoutsurvival.wiki/ja/vip-post/%E7%B7%8F%E5%90%88%E6%A1%88%E5%86%85/) ／ [豊穣の宴FAQの必要数](https://www.whiteoutsurvival.wiki/ja/vip-post/%E8%B1%8A%E7%A9%A3%E3%81%AE%E5%AE%B4%E3%80%80faq/)

## 月間チャージギフトは、到達したランクの報酬を確認

公式wikiの月間チャージギフトの説明では、到達した最上位ランクの報酬のみが届く仕組みです。例えばゴールドに達しても、ブロンズとシルバーのギフトが別々に追加で届くわけではありません。ランクごとの詳しいアイテム数は非公開と案内されています。

ゲーム内のチャージポイント・月間ギフト・Google Play Pointsは、それぞれ集計条件が違います。報酬を重複計上したり、ランク到達のために予定外の購入を増やしたりせず、実際に利用できる特典で考えましょう。 [公式wikiの月間ギフト案内](https://www.whiteoutsurvival.wiki/ja/vip-post/%E7%B7%8F%E5%90%88%E6%A1%88%E5%86%85/)

## 寒霜の星は、買う時と使う時を分ける

| 操作 | 累計チャージイベントの扱い |
| --- | --- |
| 公式Webショップで寒霜の星を購入 | この段階では対象外 |
| ゲーム内メールで受取 | 星が反映される（この段階ではパック未購入） |
| 寒霜の星で対象の有料パックを購入 | 累計チャージの対象 |

公式wikiにある「ダイヤ購入イベントの対象外」は星の購入時点の説明です。星を使えばすべてのダイヤ購入イベントにも加算されるとは断定できません。各イベントの説明も見ておきましょう。

また、公式ショップではGoogle Playギフトカード残高を使えません。WebとGoogle Playで決済する場合とでは、支払い方法とポイント獲得の扱いが違います。

## 豊穣の宴では、無料枠も用意されている

公式wikiの「豊穣の宴」FAQでは、大歓喜セールに無料枠と800円〜15,800円の有料枠があり、期間中それぞれ1回利用できると案内されています。大溶鉱炉Lv.10が表示条件で、選べる内容は王国の進行状況によって変わります。

豊穣の祝福パックにも無料枠があります。公式FAQの公表日程はUTCのため、日本時間に直すと次のようになります。

| 商品・イベント | 日本時間の公表予定 |
| --- | --- |
| 豊穣の祝福パック・累計チャージギフト | 11/24 9:00〜12/1 8:59:59 |
| 希望の荘園装飾パック | 11/26 9:00〜12/1 8:59:59 |
| 大歓喜セール | 11/27 9:00〜11/30 8:59:59 |

公式FAQが示す開始日のUTC 0時と終了日のUTC 23:59:59を日本時間に換算した予定です。実際の開催・内容・対象王国についてはゲーム画面を優先します。 [公式イベントFAQ](https://www.whiteoutsurvival.wiki/ja/vip-post/%E8%B1%8A%E7%A9%A3%E3%81%AE%E5%AE%B4%E3%80%80faq/)

## 豊穣の祝福パックと大歓喜セールは、無料枠も購入上限も違う

| パック | 円価格の枠 | 購入上限 |
| --- | --- | --- |
| 大歓喜セール | 無料、800〜15,800円の5つの有料枠 | 各1回 |
| 豊穣の祝福パック | 無料、800円、1,600円、3,200円、8,000円、15,800円の2枠（計7種類） | 最後の15,800円枠は3回、その他各1回 |
| 希望の荘園装飾パック | 1,600円、3,200円、8,000円、15,800円 | 15,800円枠は5回、その他各1回 |

同じ15,800円でも、別の商品枠として扱われます。大歓喜セールと豊穣の祝福パックの無料分を先に見て、装飾・アイテムのうち自分に必要な内容を選ぶのが良さそうです。サーバーの進行状況で商品内容は変わります。購入上限まで使うことを前提にする必要はありません。 [豊穣の宴公式FAQ](https://www.whiteoutsurvival.wiki/ja/vip-post/%E8%B1%8A%E7%A9%A3%E3%81%AE%E5%AE%B4%E3%80%80faq/)

## 購入先比較に必要な数字

比較には同じ円予算で購入できる寒霜の星の数量、ゲーム内で同一パックを購入するための数量、ゲーム独自の還元、Google Playのポイントを用います。仮にWeb側で5%多い同じ通貨を得られるなら、Google Play側の割引が約4.76%で同じ単価になります。これは計算例で、現在のホワサバの増量率ではありません。

## 800円のパックなら、星を買う単価はどこまでが目安？

例えば同じ800円のパックに寒霜の星499個が必要な場合、Webで購入する星の実質単価の分岐点は800÷499＝約1.6032円/個です。これは499個を使う分の費用を比べる計算で、購入する星の総数や支払総額が499個分と一致するとは限りません。対象のGoogle Play決済で税込800円・税率10%・ダイヤモンド2pt/100円を仮定すると約15pt。1ptを1円相当で使えるなら、比較に使う実質負担は785円、星の目安単価は約1.573円/個です。

この試算は星を必要数だけ消費する場合のものです。実際にはWebの星は決まった商品単位で買うため、支払総額、購入後に余る星、累計チャージ報酬、決済手数料等も含めて比べます。公式のWeb商品価格は未確認のため、最安経路を断定しません。

## 公式の購入先であることを確かめる

公式wikiの寒霜の星の項目から案内されている購入先は[寒霜の星ショップ](https://pay.whiteoutsurvival.com/)です。アクセス時はCentury Gamesのストアに転送されます。公式ストアの最新の日本円価格・増量数はログイン前の公開資料では取得できていません。

まずゲーム内で欲しいパックと必要数を決め、次に自分のキャラクターと受取先、最後に購入時の円価格と還元を見比べる。この順番なら、星を余らせにくくなります。
