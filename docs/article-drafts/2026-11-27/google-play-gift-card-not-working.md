# Google Playギフトカードが使えない・チャージできないときは？エラー別の確認方法

コンビニでGoogle Playギフトカードを買って、いざコードを入力してみたらエラーが出る。すでにお金を払っているだけに、残高に反映されないと焦りますよね。

ギフトカードが使えないときは、まず画面に出ているメッセージを見てみましょう。入力の問題なのか、販売店での有効化が必要なのか、それともGoogleアカウント側の確認が必要なのかによって、相談先も変わります。

## いま表示されているエラーはどれ？

| 表示・症状 | 最初に見るところ |
| --- | --- |
| コードに問題がある、読み取れない | 入力した文字、カードの有効化 |
| すでに利用されている | コードを登録したアカウントの残高 |
| 詳しい情報の提供が必要 | Google公式の調査フォーム |
| 本人確認を求められる | お支払いプロファイルの通知 |
| 国・地域が違う | 購入国、現在地、アカウントの通貨 |
| 利用限度に達した | 現在の残高と利用上限 |
| コードが無効・キャンセル済み | 購入した販売店 |

何度も同じコードを入力するよりも、表示された内容に合わせて確認するほうが解決に近づきます。

## コードが読み取れないなら、入力と有効化を分けて考える

Playストアを開き、右上のプロフィール画像から「お支払いと定期購入」→「コードの利用」へ進みます。カードのスキャンを試し、読み取れない場合は文字を手入力してみてください。スペースやハイフンは不要です。メールなどで受け取ったコードは、前後に余計な文字が混ざっていないかも見ておきたいところです。

それでもエラーになる場合は、購入したカードが有効化されていない可能性があります。実店舗での有効化はGoogleが代行できないため、レシートとカードを持って購入店に相談しましょう。店舗側で有効化済みと確認できたのに使えないときは、Google Playのサポートへ進みます。

## 「すでに利用されています」と出たら、残高を見る

コードを使った覚えがある場合、もう残高に加わっているかもしれません。Playストアのプロフィール画像からアカウントを確認し、「お支払いと定期購入」→「お支払い方法」でGoogle Play残高を見てみましょう。

スマホに複数のGoogleアカウントを入れている人は、別のアカウントで登録していないかも見ておくとよさそうです。登録した残高を通常の操作で別のアカウントへ移すことはできません。身に覚えのない利用や誤登録については公式窓口へ相談できますが、移行や返金が認められるとは限りません。

## 「詳しい情報が必要です」は、公式のフォームへ

購入時の情報や書類が必要という案内が出た場合は、Google公式の[ギフトカードのトラブル解決ページ](https://support.google.com/googleplay/answer/11564359?hl=ja)から、該当する調査フォームへ進みます。アカウントの本人確認を求められた場合は、画面の案内とお支払いプロファイルの通知を見て手続きします。

カードのシリアル番号が分かる写真や購入証明は、必要に応じて用意しておきましょう。ギフトコードそのものをSNSに載せたり、非公式の相手に送ったりする必要はありません。調査期間や解除の可否は個別の状況によります。

## 国や残高上限が原因になっていることも

日本向けのカードは日本の利用条件に従います。購入した国、現在地、Playの国、支払いプロファイルの通貨が一致しているかを確認しましょう。エラーを解消するためだけに国設定を変更するのは避けたいところです。ポイントや残高にも影響があります。

また、日本のGoogle Play残高の保有上限は20万円です。残高が上限に近いときは追加できないことがあります。Googleは利用限度のエラーに対して、残高の一部を使い、24時間ほどおいてから再度試す方法を案内しています。24時間で必ず解決するという意味ではありません。

## 返品や返金はできる？

ギフトカードとチャージ済みのプリペイド残高は、法律上の例外などを除き、原則として払い戻し・譲渡ができません。Google Playストアで購入したデジタルギフトカードには、届かない、不良品、記載された説明と異なるといった場合の例外が案内されています。購入先やエラーの内容で相談先が異なるため、最初から新しいカードを買い直さないようにしましょう。

## 問い合わせ前に、これだけ手元に残しておこう

購入日・店舗名、レシートや注文確認メール、エラーメッセージ、利用したGoogleアカウントを整理すると、状況を説明しやすくなります。カードも解決するまでは手元に残しておきたいですね。

チャージが済んでから対象商品を購入することでPlay Pointsが貯まるのが通常の流れです。まずは今回購入した分がきちんと残高に入ったか、落ち着いて一つずつ確かめてみましょう。
