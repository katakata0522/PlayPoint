# Google Play残高を使い切る方法｜余った10円・100円はどう使う？

ギフトカードでゲームに課金したあと、Google Playに137円だけ残ったとします。137円ちょうどの商品を見つけるのは、なかなか難しそうですよね。

でも、残高と同じ金額の商品を探さなくても使い切れる場合があります。普段買っているゲームのパックやマンガなどがあれば、次の購入で残高を優先して使うのが自然です。

## 残高より高い商品を買うと、不足分を別の方法で払える場合がある

Google Playで対象商品を購入する際、残高が価格に届かない場合は、ほかの支払い方法と組み合わせられることがあります。

| 手元の残高 | 購入予定の商品（仮の価格） | 併用払いできる場合の追加支払い |
| ---: | ---: | ---: |
| 10円 | 160円 | 150円 |
| 100円 | 480円 | 380円 |
| 137円 | 480円 | 343円 |
| 500円 | 1,000円 | 500円 |

137円を残したくないからといって、新しくギフトカードを買い足さなくてもいいのがポイントです。次に予定していた480円の商品に充てられれば、その購入の追加支払いは343円になります。

定期購入や外部ストアなどでは条件が異なります。定期購入の初回やプラン変更時に併用払いを選べることがあっても、毎回の更新時に同じ方法が使われるわけではありません。購入確定前の内訳に残高が含まれているかを見るのが大切です。

## 10円・100円未満なら、次の買い物に回す

ほんの少しだけ残っている場合は、無理に少額商品を探さず、次に買うつもりだったものに充てる方法を先に考えてみましょう。たとえば残高10円を使うためだけに160円の商品を買うと、必要のなかった150円を支払うことになりかねません。

日本の通常のギフトカード由来の残高には有効期限がないと案内されています。Play Pointsから交換したクレジットやキャンペーンでもらった残高は別で、期限を確認する必要があります。

## 100円以上あれば、ゲーム以外にも目を向けてみる

| 買い物の候補 | 見つけるときの目安 |
| --- | --- |
| いつものゲームの少額パック | もともと購入予定があるか |
| 電子書籍・マンガ | 読みたかった巻があるか |
| 買い切りアプリ | 普段使う機能を買い切りで利用できるか |
| 対象アプリ内の購入 | Google Playの決済を使えるか |

具体的な販売価格は作品や時期によって変わります。価格順に無理に買い物を探すより、欲しかったものの購入画面を開いて、残高が使えるか見てみるのがおすすめです。

なお、Google Storeのスマートフォンなどの端末購入にはGoogle Play残高を使えません。

## 残高を使ったあと、いくら支払う？

購入予定額から利用する残高を引けば、併用払いの追加支払いの目安になります。逆に、商品が残高より安い場合は、購入後に残る金額を計算できます。

たとえば残高が500円、商品が320円なら、残るのは180円。商品が800円なら、併用払いできる場合の追加支払いは300円です。クーポンがある場合は、実際の決済画面に表示された割引後の支払額を基準に考えましょう。

## 余った残高を家族に渡したり、現金に戻したりできる？

プリペイドのPlay残高は、法律上の例外などを除いて払い戻しや譲渡ができません。別のアカウントへまとめたり、Google Payへチャージしたりする用途にも使えません。余った残高は、使えるアカウントのGoogle Play対象商品へ充てるのが基本です。

## 次の交換は、使う予定が見えてから

Play Pointsを持っている場合、何となくクレジットへ交換しておくより、買いたい商品が決まったところで必要な分を交換すると余りにくくなります。交換して受け取ったクレジットには1年間の期限があるため、期限がない通常のギフトカード残高とは分けて考えておきたいですね。

残高をゼロにすることそのものを目的にせず、いつもの買い物を少し安くできたら十分。まずは次に使う予定のアプリやゲームから考えてみてください。
