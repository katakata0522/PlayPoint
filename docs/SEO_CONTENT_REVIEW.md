# SEO記事整理メモ

更新日: 2026-07-30

## 今回実施した整理

### 統合

| 旧ページ | 統合先 | 理由 |
|---|---|---|
| `/articles/2025-12-25-playpoints-not-reflected.html` | `/articles/2026-03-10-play-points-reflection-timing.html` | 「ポイントが反映されない」という同じ検索意図に対して内容が重複していたため |
| `/en/articles/google-play-points-reflection-timing.html` | `/en/articles/google-play-points-not-showing.html` | 英語圏の「not showing / reflection timing」が同じ確認手順を求める検索意図だったため |

旧URLは301転送し、内部リンク・サイトマップ・hreflangは統合先へ更新する。

### 更新対象

検索時に結論を早く確認したい主要10記事へ、次の構造を追加する。

- 冒頭の短い「先に結論」
- 「判明していること／このサイトからは不明なこと」
- 条件を自分の数値で確認する計算機導線
- 関連する記事から引用用比較表への固定リンク

### 分けたまま維持する検索意図

次の組み合わせは似ていても、利用者が求める答えが異なるため統合しない。

| ページ群 | 分ける理由 |
|---|---|
| 1ポイント、100ポイント、500・1,000ポイント | 1ポイントの意味、目標額、まとまったポイントの価値で目的が異なる |
| ダイヤモンド特典、ダイヤモンドは得か | 特典確認と費用対効果の判断で目的が異なる |
| ギフトカード、割引ギフトカード | ポイント対象の確認と購入前の割引確認で目的が異なる |
| 常設キャンペーン解説、年始キャンペーン | 一般的な判断方法と期間限定の記録で目的が異なる |
| 映画・書籍、サブスクリプション | コンテンツ購入と継続課金で確認条件が異なる |

## Search Consoleデータが必要な判断

現時点では、この作業環境から `playpoint-sim.com` のSearch Console実績へアクセスできない。表示回数や流入を推測して、韓国語・繁体字ページの増補、古い記事のnoindexを行ってはいけない。

Search Consoleの直近90日データを取得できたら、次の基準で再判定する。

1. 韓国語・繁体字は、ページまたは対応クエリに表示実績があるページだけを増補する。
2. 表示実績があり順位が低い記事は、クエリに対する即答・具体例・公式根拠を追加して更新する。
3. 検索意図が別記事と一致する古い記事は、内容を移して301統合する。
4. 表示も流入もなく、内部導線や資料価値もない記事だけを非掲載候補にする。
5. 非掲載前に、期間比較、URL変更履歴、季節性、被リンク、他ページの補助価値を確認する。

必要なエクスポート:

- 検索パフォーマンス「ページ」: 直近90日と前年同期
- 検索パフォーマンス「クエリ」: 直近90日
- 国フィルタを使った韓国・台湾のページ実績

## クリック深度

`node scripts/site-click-depth.cjs` で、サイトマップ掲載記事がトップから3クリック以内かを検査する。公開前チェックにも組み込み、未到達または4クリック以上のページがあれば失敗させる。
