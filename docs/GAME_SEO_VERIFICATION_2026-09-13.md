# Game SEO verification / content architecture — 2026-09-13

## 目的

ゲーム別ページを「ゲーム名を差し替えた課金計算テンプレート」ではなく、購入前の意思決定に使える検索資産へ育てる。

この領域では検索流入より正確性を優先する。価格・ガチャ仕様・定額商品・Webショップ差・Google Play Points対象可否が確認できない場合、推測値を公開しない。

## 公開ルール

### 1. 数値の正本

優先順位は次の通り。

1. ゲーム運営の公式お知らせ / 公式FAQ / 公式Webショップ
2. Google Play公式ヘルプ / 実際のGoogle Play購入画面
3. 開発・配信元が運営する公式コミュニティで現在価格が確認できる掲載
4. 二次情報は発見・差分検知に使うが、固定価格を確定する唯一の根拠にはしない

同じゲームでも App Store、Google Play、PC、公式Webショップで価格・付与量が異なる場合があるため、購入経路を混同しない。

### 2. 確認できない価格は fail closed

- 古い価格を「参考値」として残して計算可能にしない。
- 現行Google Play価格を一次表示で再確認できない場合は、ユーザーが購入画面の金額を自由入力してPlay Pointsだけ計算できる状態へ落とす。
- 「天井○円」は、無料通貨・所持通貨・初回増量・月パス・配布で実支払額が変わるゲームでは固定値として断定しない。
- 確定召喚の必要通貨と、確認済み販売パックから厳密に最小額を出せる場合のみ「ゼロからの最小購入例」を掲載する。

### 3. Play Pointsの扱い

日本の通常獲得率はGoogle Play公式の国別表を正本とする。

- Bronze: 1 pt / 100円
- Silver: 1.25 pt / 100円
- Gold: 1.5 pt / 100円
- Platinum: 1.75 pt / 100円
- Diamond: 2 pt / 100円

サイト内の円額→ポイント表は購入額を使った参考換算。Google公式はポイント計算で税を除外するため、最終値はGoogle Play購入確認画面の「獲得予定ポイント」を優先する。

ゲーム個別の特別獲得率は通常獲得率と加算しない。Google Play画面に表示される適用レートを正とする。

### 4. Play Points対象経路を分ける

- Google Play上の対象購入: Play Points比較対象
- ゲーム公式Webショップ / 独自チャージセンター: Google Play購入ではないため、Play Points獲得を前提にしない

Webショップの増量率とPlay Pointsの価値を無理に同じ円価値へ変換しない。Play Pointsの交換先・必要ポイントはアカウントや時期で変わるため、現在の「使う」画面を確認する。

## 記事を分ける基準

1ゲーム1ページへ何でも詰め込むのではなく、ユーザーの意思決定が独立している場合だけ深掘り記事を作る。

独立記事にできる例:

- `天井 / 確定召喚はいくら？`
- `月パス / 定額商品の通常課金比お得度`
- `Google Play課金 vs 公式Webショップ`
- `期間限定の月1回商品・セール・増量商品の通常購入比`
- `Play Pointsのゲーム別交換先 / クーポンが本当に得か`

分けない例:

- 数行で終わるパック価格だけの記事
- 本体ページと検索意図が同じ記事
- 公式情報を言い換えただけで独自計算・比較・判断がない記事

各独立記事は最低でも以下のうち3項目以上を満たす。

- 先に結論
- 現行価格 / 商品構成
- 通常購入との数量・率比較
- 天井 / 交換までの必要量の計算
- Play Pointsステータス別の参考換算
- Google Play外決済との違い
- 条件・例外・誰に向くか
- 最終確認日と公式出典

## 2026-09-13 第1波

### FGO

確認済み:

- Google Play版の有償1個販売は終了
- 480円: 有償4 + 無償1 = 5
- 1,600円: 有償13 + 無償8 = 21
- 3,000円: 有償25 + 無償16 = 41
- 4,900円: 有償42 + 無償35 = 77
- 10,000円: 有償86 + 無償82 = 168
- 確定召喚は330回
- +1ボーナス召喚も330回へカウント
- 30セットの11回召喚 = 消費聖晶石900個
- 900個以上を確認済みパックだけでゼロから最安に用意する一例: 54,600円 / 902個
- 2026年11周年福袋は有償15個
- 有償15個をゼロから最安に用意する一例: 480円×4 = 1,920円 / 有償16個

追加記事:

- `/games/fgo/pity-cost/`

本体ページも同じ正本へ修正し、旧160円・1,400円・2,900円等を削除。

### 原神

確認済み / 修正:

- 空月の祝福: 610円
- 購入時創世結晶300
- 30日間、ログイン日に原石90ずつ。全受取で2,700原石
- 創世結晶を原石へ1:1変換する前提の最大値は合計3,000原石相当
- 980+110帯の掲載価格: 1,840円。旧1,220円を修正

方針変更:

- 90連=約27,000円、180連=約54,000円という固定プリセットを廃止
- 最大必要原石と実際の購入額を分離する
- 所持原石 / 空月 / 初回2倍 / 配布等を無視した固定円額をSEO見出しにしない

追加記事:

- `/games/genshin/welkin-value/`

注意: 原神の価格は現在公開されているHoYoLAB価格スナップショットを用いている。購入直前のAndroid Google Play表示を最終正本とする。

### ブルーアーカイブ

確認済み:

- 2026-07-29以降、旧「呼び出しポイント」方式ではなく「呼び出しチャージ」
- 100チャージで★3確定、対象PUは50%
- 200チャージで対象PU確定

未確定:

そのため固定の48,000円天井プリセットを撤去。現行Google Play価格を一次表示で再確認できるまでは、固定パック価格を計算候補として提示せず自由入力へfail closedする。

## 新規ゲーム候補

新規ページは売上ランキングだけで作らず、Google Play課金と比較価値が確定できたものから追加する。

優先調査:

- Pokémon GO
- eFootball
- プロ野球スピリッツA
- ホロライブドリームス
- Last War
- Whiteout Survival

特に「公式Webショップがある」「サブスクがある」「月1回お得商品がある」「大きな通貨パック差がある」タイトルは、PlayPointの『何ポイント貯まるか』と組み合わせた検索価値が高い。

## 今後の自動監査候補

- `verification` が `official` / `current-published-price-snapshot` / `pending` のどれかを全ゲームで持つ
- 最終確認日から一定期間を超えた固定価格を警告
- `pending` のゲームで固定価格プリセットが公開されていたらCI失敗
- 深掘り記事のcanonical / sitemap / 親ゲームページ導線をCI確認
- Web決済ページに「Google Play Pointsが付く」と誤記していないことを検査
- 同じ価格・天井値が複数ファイルへ直書きされないようSSOT化を継続
