# 第2章・著者紹介の同言語導線（2026-09-17）

## 範囲

PR #337 の基準台帳に続く実修正。英語・韓国語・繁体字の利用中に著者紹介だけ日本語になる問題を扱う。デザイン、計算条件、保存形式、法務ページ、記事本文の事実・更新日は変更しない。

## 対応する生成元と実行時

| 対象 | 修正責務 |
| --- | --- |
| 多言語トップ | `language-page-builder.cjs` と `locale-config.cjs` で本文・フッター・著者行を同言語へ向ける。 |
| JavaScriptでの文言更新 | `js/config.js` の著者リンクを同じURLへ。`js/ui.js` はルート相対URLをそのまま保持し、従来の相対・外部URLの挙動は保つ。 |
| 香港・インド | `region-page-sync.cjs` と `region-expansion-config.js` で既存の繁体字・英語プロフィールへ。香港・インド用プロフィールを架空に作らず、可視ラベルに遷移先言語を示す。地域の計算条件は変えない。 |
| ゲーム計算ページ・一覧 | `generate-game-simulators.cjs` の著者リンクにアセット用の階層を流用しない。著者の構造化データURLも同言語に合わせる。 |
| 生成LP・記事 | `intl-seo-pages.cjs` の著者行・関連リンク・構造化データを同言語へ。 |
| 手書き海外記事 | `intl-article-layout.cjs` の既存正規化に二階層の相対パスを追加し、割引ガイド3件の旧著者行を補正する。 |
| 手書き海外LP9件 | `site-shell.cjs` の同言語プロフィールを `insert-lp-footers.cjs` から継続同期。`build-html.js` に明示的な呼び出しを追加。本文は書き換えず、管理フッターが異常なら停止する。 |

## 再発防止

- 公開HTML全体から著者リンクを抽出し、同言語・実在するファイル・香港/インドの可視言語注記を検証する。リンクを削除して0件にする実装は通さない。
- 6地域の実ランタイム `UI.updateUIText()` と静的HTMLでURL・ラベルが一致することを検証する。
- 手書きLPの二度目同期が変更0件であること、本文・法務リンク・対象外ファイルを保つことを検証する。
- 二階層相対パスを持つ記事の同期が冪等で、外部URLと本文を変更しないことを検証する。
- 日本語URLを固定していた既存3検査は削除せず、正しい同言語導線の期待値・契約へ更新する。
- 既存 `browser-smoke.cjs` に静的/実行後の著者URL確認と、実クリック後の到達先言語確認を追加。PR Gateと本番検証が同じ検査を使用する。ブラウザの成否は実行結果で判断する。
