# Search Console 改善メモ テンプレート

Search Console の実データを根拠にページを改善するときは、変更前にこの形式で記録する。目的は「何となくSEO改善」を避け、対象クエリ・変更理由・確認日を1対1で追えるようにすること。

## 基本情報

- 記録日: YYYY-MM-DD
- 対象URL: `/path/`
- 対象地域/言語: JP / EN / KO / TW / HK / IN
- 対象期間: 過去28日 / 前期間比較 / その他
- 次回確認日: YYYY-MM-DD

### 問題の分類

該当するものだけ残す。

- 表示回数はあるがCTRが低い
- 掲載順位5〜20位で改善余地がある
- クエリ意図とtitle/descriptionがずれている
- 同じ意図で複数URLが競合している
- 記事流入はあるが計算機への遷移が弱い
- LPへの遷移はあるが計算完了が弱い
- 国/言語別で伸びているが対応ページが弱い
- その他
