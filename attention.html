Which mode can I use?

🇺🇸 English / US mode

Same calculation profile:

United States, United Kingdom, France, Germany, Italy, Spain

These countries use 1 point per 1 local currency unit at Bronze, the same level thresholds, the same multipliers, and Diamond at 10,000 points. The screen still displays $, so UK and euro-area users should read the number as their own local currency.

🇯🇵 Japanese / Japan mode

Exact match: Japan only

Countries that look similar, but should not use a substitute mode

A matching threshold or multiplier is not enough. The earning unit and highest level must also match.

Hong Kong — same rank structure as Japan/Taiwan, different earning unit

Hong Kong uses the same 250 / 1,000 / 4,000 / 15,000 thresholds and 1.0 / 1.25 / 1.5 / 1.75 / 2.0 multipliers, but earns 1 point per HK$7. Japan uses ¥100 and Taiwan uses NT$30, so neither mode gives correct amount calculations for Hong Kong.

US-like through Platinum, but not a full US-mode match

1 local currency unit, but the current official table is not a full five-level US match:
Australia, Austria, Belgium, Brazil, Finland, Greece, Ireland, Netherlands, New Zealand, Portugal, Switzerland

Same 150 / 600 / 3,000 thresholds through Platinum, but a different earning unit:
Denmark (6 DKK), Norway (6 NOK), Sweden (7 SEK), Israel (3 ILS), Saudi Arabia (4 SAR), South Africa (17 ZAR), United Arab Emirates (4 AED)

Countries with their own thresholds or earning units

Chile, Czech Republic, India, Indonesia, Mexico, Poland, Thailand, and Turkey use country-specific combinations. Do not use the US, Japan, South Korea, or Taiwan mode for level-up estimates.

What should I do if there is no exact mode?

  1. Open Google Play and check the earning rate and level requirements shown for your account country.
  2. You may use the calculator's direct earning-rate input for a simple purchase-point estimate.
  3. Do not rely on rank-up, maintenance, or required-spend results unless your country is listed as an exact calculation match above.
